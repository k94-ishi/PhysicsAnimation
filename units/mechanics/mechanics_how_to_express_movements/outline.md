# mechanics_how_to_express_movements

## Goal
Learn how to represent motion using graphs, and understand how position,
direction, and speed can be read off them.

## Audience
High school students learning motion graphs for the first time.

## Prerequisites
- The basic meaning of position and time
- The idea of a coordinate axis
- Basic graph-reading skills

## Lesson flow
1. Observe something moving, and think about a position-time graph.
   1. Watch "😁" move back and forth along a straight line, and get students thinking about how to express that motion with numbers.
   2. Add ticks to the line to turn it into a coordinate axis. Display the coordinate above "😁" as it keeps moving, showing its position.
   3. Frame knowing the motion as wanting to know "where it was, and when" - and add a timer alongside "😁"'s motion.
   4. Set up x-t graph axes here: explain the vertical x axis and horizontal t axis. Get students thinking about how to represent this motion on the graph.
   5. Connect "😁"'s position (still moving) to the corresponding point on the graph's x axis with a line, showing that the two move in lockstep.
   6. Next, get students thinking about plotting the graph over time. Reset the running timer to 0 and stop "😁"'s motion.
   7. Start the timer and set "😁" moving again, plotting it on the x-t graph at the same time. Before plotting starts, the x-axis point and "😁"'s position are connected by a line; once motion starts, the plotted point (t, x) and "😁"'s position are connected by a line instead.
   8. Once the plot reaches the edge of the graph, change the initial position and plot again.
   9. Once that plot reaches the edge of the graph, set the timer and initial position to start before t<0, and plot once more.
2. Focus on speed.
   1. Explain adding a velocity value to "😁"'s motion from before.
   2. Observe the motion and identify, from "😁"'s actual movement, the points where velocity is zero, maximum, and minimum.
   3. Plot the x-t graph again and check where those points land on it. Mark the zero/maximum/minimum-velocity points on the graph.
   4. Confirm, at the point of maximum velocity on the x-t graph, that velocity corresponds to the slope of the tangent line there, and ask how that slope can actually be computed.
   5. Zoom in on the tangent at the maximum-velocity point and compute the slope concretely: show the increase in x over the increase in t as an equation using actual values from the graph, and work it out.
   6. Re-emphasize that average velocity is displacement divided by time.
3. Connect to the velocity-time graph.
   1. Add a v-t graph to "😁"'s motion and the x-t graph, built the same way as before.
   2. Show a few different motion patterns.
4. Wrap-up.
   1. Show "😁"'s motion together with the x-t and v-t graphs, highlighting that v is the slope on the x-t graph, and close by noting that we've now seen how to handle "😁"'s motion - something originally unrelated to numbers - using numbers.
