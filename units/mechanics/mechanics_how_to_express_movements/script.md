# script.md

This is a script draft for the explainer video, written to follow the
"Lesson flow" in `outline.md`.

## 1. Observe something moving, and think about a position-time graph
First, let's watch "😁" move back and forth along a straight line.
How could we express this motion with numbers?

## 2. Add ticks to the line to make a coordinate axis
To represent the motion's position, let's add ticks to the line like this to make a coordinate axis.

We'll keep a coordinate shown above "😁" as it keeps moving, giving its position.

## 3. Watch the position change over time
Position alone doesn't really capture motion, does it? Let's make it so we can see where "😁" is together with the time, as it moves.

## 4. Set up the x-t graph axes
Now let's set up the axes for an x-t graph.
The horizontal axis is the t axis, representing elapsed time, and the vertical axis is the x axis, representing position.

Let's use this graph to see how we can represent the motion.

## 5. Connect the position to a point on the graph's x axis
Without worrying about time for now, we've connected "😁"'s ever-changing position to the corresponding point on the x axis with a line. You can see the two move in lockstep.

## 6. Think about plotting the graph over time

We just said position alone doesn't capture motion. Let's think about plotting the graph as time passes.

First, let's reset the timer to 0 and stop the motion for a moment.

Now we'll restart the timer and set "😁" moving again. On the graph, as time passes, the point marking the motion moves to the right - so after 3 seconds, a point will land somewhere on this line, and after 6 seconds, somewhere on that line.

Let's start the motion and plot it.

## 7. Change the initial position
Now let's change the initial position and watch again.

Next, let's set the timer to start before time zero, and plot once more.

This is how we can represent an object's motion with an x-t graph.
Does that give you a feel for it?

## 8. Focus on speed
Next, let's focus on speed. We'll add a velocity value to "😁"'s motion. Pay attention to the points where the velocity is zero, where it's maximum, and where it's minimum.

How did that look?
Moving backward corresponds to negative velocity, so note that the point of minimum velocity happens while "😁" is moving backward.

## 9. Check the zero/maximum/minimum velocity points on the graph
Let's see where these points land on the x-t graph.

## 10. Velocity corresponds to the tangent line's slope
Velocity corresponds to the slope of the tangent line on the graph.

For example, at the point of maximum velocity, the tangent's slope is steep.

Let's think about how we can actually compute that slope.

## 11. Compute the tangent's slope concretely
Let's zoom in on the tangent.

Do you remember how to compute a slope?
We can do it in two steps.
Step 1: pick an interval, look at the tangent, and find the increase in t and the increase in x.
Step 2: divide the increase in x by the increase in t.

That gives us the slope.
It matches the maximum velocity we saw on the graph earlier - so we can see that the slope of the tangent on the x-t graph at a point is the velocity at that point.

## 12. Connect to the velocity-time graph
Let's look at the same motion again, this time on a velocity-time graph.

On the position-time graph, we saw "how much the position changed."
On the velocity-time graph, we see "how the speed itself is changing."

## 13. Wrap-up
Finally, let's look at the x-t graph, the v-t graph, and "😁"'s motion side by side.

Do you have a feel for these graphs now?
